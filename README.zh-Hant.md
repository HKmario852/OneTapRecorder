# OneTap Recorder · 一鍵錄影

[English](README.md) · [下載 Windows x64 版本](https://github.com/HKmario852/OneTapRecorder/releases)

一個按鈕開始／停止，支援錄製螢幕與聲音，或者只錄聲音。

## 使用方法

1. 先退出舊版，下載並完整解壓 ZIP，再開啟 `OneTapRecorder.exe`。
2. 選「螢幕與聲音」（MP4，最高 1080p／30 fps）或「只錄聲音」（WAV，48 kHz 立體聲）。
3. 電腦聲音、咪高峰可獨立開關。純錄音至少要開啟一個來源。
4. 按大按鈕開始，再按一次停止並儲存。
5. 右上角 EN／繁 可切換英文／繁體中文，並記住選擇。

預設快捷鍵 `Ctrl + Shift + F9`。可按「設定快捷鍵」改成 F8 等單鍵或其他 Ctrl／Alt／Shift 組合。Windows 鍵及 F12 不適用；如被佔用會保留原設定。

## 背景及系統匣

按 × 只隱藏視窗，錄製會繼續。喺 Windows 右下角系統匣或 ^ 隱藏圖示區搵到程式圖示，雙擊重新開啟；右鍵可開始／停止、開啟儲存資料夾或「結束程式」。結束前會先儲存。再開啟 exe 會帶返出現有視窗。

錄製中，系統匣及視窗圖示會變成紅色圓底＋白色停止方塊，工作列亦會加上狀態標記；儲存中轉黃色，完成後還原。錄影及純錄音都適用，沒有閃爍或額外背景計時器。

預設儲存到「影片」資料夾內的 `OneTap Recordings`，可更改。所有檔案只留喺本機，沒有上傳、分析追蹤、背景網絡輪詢或開機自動啟動。

## v0.4 資源優化

隱藏／最小化時停止介面計時器；顯示時每秒更新一次。系統匣提示只喺狀態改變時更新。純錄音由每 20 ms 改為每 100 ms 批次寫入，保持取樣率及音訊格式。影片元件延至需要錄製畫面時初始化。

同一電腦 15 秒樣本中，背景錄音 CPU 由單核心約 1.77% 降至 0.94%，隱藏介面更新由 60 次減至 0 次。閒置私人記憶體仍約 102 MiB。短測數據包含量度開銷，不代表所有電腦，亦不代表完全零資源使用。詳見 [驗證紀錄](docs/VALIDATION.md)。

## 注意事項

Windows 10/11 x64；已附 .NET 執行環境。其他電腦可能需要 Microsoft Visual C++ x64 Redistributable；Windows N/KN 可能需要 Media Feature Pack。下載版本未經數位簽署。

聲音來自錄製開始時的預設音訊裝置；更換裝置後請重新開始。WAV 約每小時 690 MB，接近 4 GB 單檔上限時會停止並提示。未全面實機驗證咪高峰／雙來源混音、長時間錄製、其他電腦及遊戲相容性。

原始碼建置需要 .NET 9 SDK：`./scripts/Build.ps1`。第三方授權見 `licenses/`；應用程式原始碼以 [MIT 授權](LICENSE) 發佈。介面文字在 `src/OneTapRecorder/Strings.resx`（英文）及 `Strings.zh-Hant.resx`（繁體中文）；診斷測試開關只喺 `Diagnostics` 建置版本提供。
